16 号工作流（动漫 / Cosplay / 放大）

开关、提示词、LoRA、底模都是从工作流里自动读出来的。关掉的分组会按 ComfyUI 的 bypass 规则跳过。

1. 分组开关

2. 底模

可以从列表里选卷上已有的模型，也可以直接输入新上传的文件名（相对 models/checkpoints/ 或 models/unet/）。换成不同架构的模型（比如 SDXL 换 FLUX）需要改工作流本身。

3. 参数

4. 提示词

只显示当前开着的分组里的提示词。

5. LoRA

每个 LoRA 加载器单独设置。文件名要和网络卷 models/loras/ 下的路径一致；自己训练的 LoRA 上传到卷上后，点"添加"填文件名即可。

6. 输入图片

当前开着的分组不需要输入图片。
